# LinkUnbound

[English](README.en.md)

LinkUnbound открывает ссылки в нужном браузере или профиле. Назначьте его браузером по умолчанию в Windows и настройте правила для сайтов, отдельных адресов и приложений, из которых приходят ссылки.

[Скачать установщик для Windows x64](https://github.com/WeslyG/LinkUnbound/releases/latest)

## Возможности форка

- **Русский интерфейс.** При первом запуске используется язык системы, если он поддерживается, иначе английский. В настройках можно выбрать русский, английский, испанский или автоматический режим.
- **Резервный браузер.** Если ни одно правило не подходит, ссылка сразу открывается в выбранном браузере. Настройка показа окна выбора при этом заблокирована с пояснением.
- **Правила по спискам доменов.** Один список подключается одним правилом. Можно выбрать условие «домен входит в список» или «домен не входит в список».
- **Встроенные и свои списки.** Подборки для России и Украины можно подключать по отдельности. В настройках видны их источники и состояние кеша. Для своего списка можно вставить домены вручную или указать HTTPS-адрес.
- **Редактирование и удаление.** Смена адреса или доменов сохраняет привязанные правила. При удалении списка приложение показывает связанные правила и после подтверждения удаляет их вместе со списком.
- **Кеш и обновление.** Можно включать применение списков, разрешать фоновое обновление, выбирать периодичность и обновлять кеш вручную. Локальные копии работают без сети.

## Формат списков

Текст в UTF-8, один домен на строку. Пустые строки и комментарии с `#` допускаются. Домен совпадает также со своими поддоменами. Запись с точкой в начале, например .example.org, совпадает только с поддоменами. Схемы, пути и маски вроде `*.example.org` не поддерживаются. LinkUnbound проверяет записи при добавлении и обновлении.

Встроенные списки берутся из [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains). Точный источник каждой подборки указан в настройках.

## Данные и обновления

В приложении нет телеметрии и функции формирования отчётов. Настройки, правила и кеш списков хранятся локально. Приложение обращается к GitHub за обновлениями и к источникам списков при их обновлении. Перед установкой обновления оно проверяет подпись установщика и номер версии.

## Как выпустить новую версию

Отправьте в форк тег в формате `vX.Y.Z`. Процесс [Windows release](.github/workflows/windows-release.yml) возьмёт версию из тега, соберёт и подпишет установщик Windows x64, опубликует релиз и обновит стабильный канал в ветке `manifest`. Ручной запуск из Actions собирает и проверяет подписанный установщик без публикации.
