# История изменений

## [Unreleased]

- Обновлены инструменты фронтенда и HTTP-клиент Rust. Убрана дублирующаяся версия HTTP-клиента, сохранён совместимый стек Tauri и Slint.
- «Остальные ссылки» всегда отображаются внизу. В разделе правил объясняется, как выбирается правило и когда влияет порядок строк.
- Быстрые изменения настроек сохраняются независимо друг от друга. Параллельные обновления одного списка доменов используют одну загрузку.
- На macOS приложение распознаёт установку из Homebrew cask `weslyg-linkunbound`.
- Исправлено извлечение иконок браузеров при одновременных запросах на Windows.

- Настроена автоматическая сборка Windows x64 и macOS для Apple Silicon и Intel. Релизы используют описание из этого файла и обновляют стабильный канал.

## [2.1.1]

- Установщик Windows регистрирует форк как отдельное приложение LinkUnbound (WeslyG), со своим браузером в настройках Windows.
- Установщик переносит настройки, правила и кеш списков из подтверждённой версии форка 2.1.0. После перехода выберите LinkUnbound (WeslyG) браузером по умолчанию.
- Добавлены установщики macOS для Apple Silicon и Intel.

## [2.1.0] - 2026-11-22

- Добавлен русский интерфейс. По умолчанию используется язык системы, а для неподдерживаемых языков выбирается английский. В настройках можно сменить язык.
- Добавлен резервный браузер для ссылок без подходящего правила. При включённом резервном браузере настройка показа окна выбора заблокирована с пояснением.
- Добавлены встроенные списки доменов для России и Украины из itdoginfo/allow-domains. В настройках указаны источники, состояние локального кеша и периодичность обновления.
- Добавлены пользовательские списки с доменами вручную или по HTTPS. Приложение проверяет формат, хранит копии локально и позволяет управлять обновлением списков.
- Одним правилом можно выбрать домены внутри списка или вне его. Редактирование списка сохраняет привязанные правила. При удалении приложение показывает эти правила и предлагает удалить их вместе со списком.
- Убраны функция формирования отчётов и ссылки на пожертвования и другие приложения из настроек. Канал обновлений переведён на этот форк, установщик Windows подписан ключом обновлений.
